# Mission 03 — Operating Systems

## Objective
Understand operating systems, processes, storage, paths, and permissions.

## Work Completed
Documented the main responsibilities of an operating system.

## Commands/Tools Used
- `pwd` — displays the current path.
- `ls -l` — displays file details and permissions.
- `ps` — displays running processes.
- `df -h` — displays available disk space.
- `du -sh foldername` — displays the size of a folder.

## What I Learned
An operating system manages computer hardware and software. It manages files, memory, devices, security, and running programs.

A process is a program that is running. Storage keeps files and data. A path tells the computer where a file or folder is located. Permissions control who can read, write, or run a file.

## Difficulties
Understanding the difference between a program and a process.

## How I Resolved Them
A program is stored instructions. A process is that program while it is running.
