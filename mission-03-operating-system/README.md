# Mission 03 — Operating Systems

## Objective
Understand the role of an operating system in managing computer hardware, software, processes, storage, and files.

## Work Completed
Studied the responsibilities of an operating system and explored processes, storage, file paths, and file permissions using Terminal commands.

## Commands/Tools Used

| Command | Purpose |
|---|---|
| `pwd` | Displays the current directory |
| `ls -l` | Shows files with permissions and details |
| `ps` | Displays running processes |
| `df -h` | Shows available disk space |
| `du -sh foldername` | Shows the size of a folder |

## What I Learned

### 1. Operating System
An operating system (OS) manages computer hardware and software and provides an environment for applications to run.

Examples: macOS, Windows, and Linux.

### 2. Processes
A process is a program that is currently running.

For example, when I open a web browser, the operating system manages its running process and the resources it uses.

### 3. Storage
Storage is used to save data and files for future use. The `df -h` command helps display disk space information.

### 4. File Paths
A file path tells the computer where a file or folder is located.

- Absolute path: Gives the complete location of a file.
- Relative path: Gives the location relative to the current directory.

### 5. File Permissions
File permissions control who can read, write, or execute a file.

The `ls -l` command displays permission information.

| Permission | Meaning |
|---|---|
| `r` | Read a file |
| `w` | Write or modify a file |
| `x` | Execute a file |

## Difficulties
Understanding the difference between a program and a process.

## How I Resolved Them
Learned that a program is a set of stored instructions, while a process is that program running on the computer.
