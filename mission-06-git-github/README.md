# Mission 06 — Git and GitHub

## Objective
Understand version control and the basic Git workflow.

## Work Completed
Documented the commands used to track project changes and upload them to GitHub.

## Commands/Tools Used
- `git status` — checks the working tree.
- `git add .` — stages changes.
- `git commit -m "message"` — saves a version of the work.
- `git log --oneline` — displays commit history.
- `git branch` — displays branches.
- `git switch -c update-about` — creates and switches to a branch.
- `git push` — uploads commits.
- `git pull` — downloads and integrates remote changes.

## What I Learned
Git is a version control system. It records changes to files. GitHub hosts Git repositories online.

The basic workflow is edit, stage, commit, and push. A branch allows work to happen separately. A Pull Request asks for changes from one branch to be reviewed and merged into another branch.

## Difficulties
Understanding the difference between Git and GitHub.

## How I Resolved Them
Git manages version history. GitHub hosts repositories and supports collaboration.
