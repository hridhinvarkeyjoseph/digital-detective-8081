## What I Learned

### 1. Types of Networks

| Network | Meaning | Example |
|---|---|---|
| LAN | Local Area Network | Home Wi-Fi |
| MAN | Metropolitan Area Network | Network covering a city |
| WAN | Wide Area Network | The internet |

### 2. Networking Concepts

- **DNS:** Converts domain names into IP addresses.
- **Router:** Connects networks and forwards data.
- **Protocol:** A set of rules that devices follow to communicate.
- **Packet:** A small unit of data sent across a network.
- **Client-server model:** A system where a client requests a service and a server responds.

### 3. How a Website Opens

1. I enter a website address in the browser.
2. The browser uses DNS to find the server's IP address.
3. The browser establishes a connection with the server.
4. It sends an HTTP or HTTPS request.
5. The server processes the request and sends a response.
6. The browser displays the website.

### 4. Networking Commands

- `ping example.com` checks whether a destination responds.
- `nslookup example.com` displays DNS lookup information.
- `traceroute example.com` helps identify the network route to a destination.
