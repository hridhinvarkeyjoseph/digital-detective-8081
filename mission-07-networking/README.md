## What I Learned
LAN connects devices in a small area, such as a home or office. MAN connects networks across a city. WAN connects networks across large geographical areas.

DNS converts a domain name into an IP address. A router connects networks and forwards data. A protocol is a set of communication rules. Packet switching sends data in small packets. In the client-server model, a client requests a service and a server responds.

### How a website opens
1. The user enters a website address.
2. The browser checks the address.
3. DNS finds the server IP address.
4. The browser connects to the server.
5. The browser sends an HTTP or HTTPS request.
6. The server sends a response.
7. The browser displays the website.
