- Web browser

## What I Learned
IPOS means Input, Processing, Output, and Storage.
- Input: Data entered into a computer, such as typing.
- Processing: The computer works on the input.
- Output: The result, such as text on a screen.
- Storage: Data saved for later use.

Hardware means the physical parts of a computer. Examples are the keyboard, monitor, and processor.
Software means programs that tell the computer what to do. Examples are an operating system and a web browser.

An ATM accepts a card and PIN as input, processes the request, displays information, and stores transaction records.
