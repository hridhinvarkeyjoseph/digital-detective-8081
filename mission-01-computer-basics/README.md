# Mission 01 — Computer Basics

## Objective
Understand the basic parts and functions of a computer.

## Work Completed
Studied the IPOS cycle, hardware, software, and examples of computer systems used in daily life.

## Commands/Tools Used
- Computer and operating system
- Web browser
- Text editor

## What I Learned

### 1. IPOS Cycle

IPOS stands for Input, Processing, Output, and Storage.

| Stage | Meaning | Example |
|---|---|---|
| Input | Data entered into a computer | Typing on a keyboard |
| Processing | Computer works on the input | CPU processing data |
| Output | Result produced by the computer | Text displayed on screen |
| Storage | Saving data for future use | Saving a file |

### 2. Hardware and Software

| Hardware | Software |
|---|---|
| Physical parts of a computer | Programs that run on a computer |
| Can be touched | Cannot be physically touched |
| Keyboard, monitor, CPU | Operating system, web browser |

### 3. Computer Systems in Daily Life

| System | Input | Processing | Output |
|---|---|---|---|
| ATM | Card and PIN | Verifies account details | Cash or transaction message |
| Smartphone | Touch and voice | Processes user commands | Screen display or sound |
| Laptop | Keyboard and mouse | Executes instructions | Display and other results |

## Difficulties

## How I Resolved Them
